ESCALATION — SAME ROUND
1st anchovy — one voice boos. Almost polite. 2nd — the whole room. Longer sample. 3rd — boo, plus a single slow clap. 4th+ — silence. Nobody boos any more. Somehow worse.
The escalation resets each round. Going quiet at four is the whole joke — the table notices the absence faster than they noticed the sound.
END-OF-ROUND BADGE
ANCHOVY LOVER RAY · 5 PLAYED Awarded to whoever played the most. Prints on their receipt at cost 0.
SOUND & ACCESSIBILITY
Three samples at 400 / 700 / 900ms, one slow clap. Ducked under any effect sound already playing — the boo never masks the chain. Muted, the visual carries it alone: the stamp plus the shove. Nothing about the round is communicated by sound only. prefers-reduced-motion — no shove; the stamp cross-fades in place. Client-side only. The server never needs to know the crowd has opinions.
07 HANDOFF
1. Replace the :root block in public/css/styles.css with za-arcade-tokens.css. Legacy names are aliased, so no selector needs editing. 2. Add the fonts to index.html — Press Start 2P and VT323, plus Kaushan Script. Bump the body font-size from 15px to 18px; VT323 runs small. 3. In public/js/cards.js, change the KINDS index values to ASCII (X, <>, +2, *, +4). Press Start 2P has no glyph for ⊘ ⇄ ★. 4. Add one .crt-overlay div to the app shell. That is the whole ambience system. 5. Card art stays PNG at 5:7. The sprite window is the only part of the frame that changes between cards, so the art can be generated once per design and dropped in without relayout — but the frame, index and banner should move into the art itself if you set USE_IMAGES = true, exactly as the current README describes. 6. Expansions in section 06 need six bot portraits (96×96 sprites, same generator as the cards), one REGULARS array in server/bot.js, a receipt built from the round's existing event list, and four short crowd samples. None of it changes a rule. Not done yet: the regeneration prompts for the 55 sprites and the 6 portraits, and the lobby/round-over mobile layouts. Say the word.
